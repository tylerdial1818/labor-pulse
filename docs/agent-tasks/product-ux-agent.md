# Product/UX Agent Task

## Objective

Define the app objective, user workflows, acceptance criteria, and UX expectations.

## Scope

- Product brief
- User journeys
- Filter and view requirements
- UX copy and acceptance criteria

## Allowed Files

- `docs/product-brief-template.md`
- `docs/design-system.md`
- `docs/metric-definitions.md`
- UX notes in feature docs

## Forbidden Files

- `src/lib/db/**`
- `src/lib/auth/**`
- Deployment credentials
- Metric formula changes without Data Model + Analytics handoff

## Implementation Steps

1. Fill out the product brief.
2. Define primary workflows and out-of-scope items.
3. Identify required filters, exports, states, and responsive behavior.
4. Add UX acceptance criteria for frontend agents.

## Test Commands

```bash
npm run lint
```

## Handoff Requirements

- Product objective
- Required views/workflows
- Acceptance criteria
- Open stakeholder questions
